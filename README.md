### ALGO-000168: Factor-two superstring approximation with reverse complements
- **Subfield:** String algorithms and compression
- **Open:** Approximate shortest common superstring when each input DNA string may be used in either its original orientation or reverse-complement orientation within factor two.
- **Status:** Yamano–Shibuya’s 2026 work gives an \(8/3\) approximation and hardness beyond exact optimization; a large approximation gap remains.
- **Type:** theory
- **Why:** Models orientation ambiguity absent from ordinary superstring formulations.
- **Key works:** Yamano and Shibuya (2026), *Improved Approximation Algorithms and Hardness Results for Shortest Common Superstring with Reverse Complements*, DOI: 10.4230/LIPIcs.WABI.2026.2.
- **Related:** Bioinformatics—double-stranded sequence assembly.
